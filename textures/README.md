# Текстуры библиотеки материалов

Источник — [ambientCG](https://ambientcg.com), лицензия **CC0 1.0** (общественное достояние, указание автора не требуется).
Исходники 2K-JPG пересжаты в WebP: color и normal (DirectX) — 2048 px, rough и disp — 1024 px.
На сайте загружаются отсюда через raw.githubusercontent.com (в деплой Vercel папка не входит — лимит 100 МБ).
Сборка заново: `node tools/serve.mjs 5173 <папка с JPG>` → `http://localhost:5173/tools/build.html`.
